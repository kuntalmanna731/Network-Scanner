# Network Scanner

A Python-based network scanning tool that discovers active hosts on a network using ICMP ping requests.

## Features
- Scan devices in a network range
- Detect active hosts
- Multi-threaded scanning for faster results
- Save scan results to CSV

## Technologies Used
- Python
- Scapy
- Concurrent Futures

## Files
- scanner_02.py
- scanner_04.py
- wrapper_scanner.py
- scan_results.csv
